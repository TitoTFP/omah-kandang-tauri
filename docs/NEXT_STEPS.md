1. Uji input dan navigasi pada tablet Android.
2. Tambahkan edit, pembatalan, dan jejak koreksi transaksi.
3. Tambahkan ekspor CSV dan cadangan database.
4. Tambahkan pengingat jatuh tempo.

6. Tambahkan sinkronisasi opsional ke server saat lebih dari satu perangkat digunakan.
7. Setelah alur stabil, tambahkan modul stok, harga pokok, dan laba.
